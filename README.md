# Fantasy Character Generator

An ancient alchemist's workbench fantasy character generator featuring stylized player cards, cartoon RPG portraits, stats, backstories, and deck collection.

![Fantasy Character Generator](https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/scroll.svg)

## ⚔️ Features

- **Character Generation**: Transmute random fantasy heroes with unique names and classes (`Mage`, `Rogue`, `Warrior`, `Ranger`, `Cleric`, `Paladin`, `Druid`).
- **Dynamic Cartoon/Video-Game Portraits**: Procedural SVG portrait engine with customizable cel-shading, gear, hair, hats, and magical auras with **Generate Portrait** and **Regenerate Portrait** capabilities.
- **Combat Attributes**: Rolls class-weighted **Health**, **Mana**, and **Strength** stats with glowing jewel meter bars.
- **Evocative Backstories**: Inscribes unique 1-to-2 sentence origin chronicles for every champion.
- **Alchemist's Workbench Aesthetic**: Atmospheric dark wood tabletop, transmutation circles, bubbling potion flasks, flickering candles, and gold/parchment styling.
- **My Deck**: Save and archive your favorite champions to a persistent grimoire deck with browser storage (`localStorage`).

## 🛠️ Tech Stack

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Google Fonts** (`Cinzel Decorative`, `MedievalSharp`, `Crimson Pro`)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Ganesh1-IFS/fantasy-character-generator.git
cd fantasy-character-generator

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Building for Production

```bash
npm run build
npm run preview
```
